# Wonderful Yapı – yeni site prototipi

Three.js + GSAP + Vite. Scroll ile çalışan 3D hero, süreç anlatımı, önce/sonra proje görüntüleyici, harita ve ön değerlendirme formu.

```
npm install
npm run dev      # http://localhost:5173
npm run build
```

Not: 3D modeller şematiktir, gerçek proje çizimlerini temsil etmez.
